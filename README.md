# Собрания созависимых в Омске

Готовый статический лендинг на русском языке: светлое оформление, адаптивная вёрстка, телефон в шапке и закреплённая кнопка звонка, адрес встречи и ссылка на карту. Основное содержимое и FAQ работают без JavaScript. Нет внешних шрифтов, аналитики, форм и зависимостей npm.

Контакт: **+7 983 621-21-48**. Место: **Омск, ул. Нефтезаводская, 10, студия подкастов**. Время, формат и условия участия уточняются по телефону. Название конкретной группы, расписание, стоимость и принадлежность к CoDA не заявлены без подтверждения организатора.

## Локальный запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна.

```powershell
npm run build
npm run check
npm run preview
```

Предпросмотр: http://127.0.0.1:4173. Каталог `dist/` содержит файлы для любого статического HTTPS-хостинга.

## Публикация

Workflow `.github/workflows/pages.yml` собирает и проверяет сайт при push и pull request. При переменной репозитория `PAGES_ENABLED=true` он публикует `dist/` в GitHub Pages при push в `main`. Источник Pages: **GitHub Actions**. Репозиторий открыт по разрешению владельца для размещения на текущем тарифе GitHub.

Основной URL по умолчанию: `https://vanyagufild666-commits.github.io/soza/`. Для собственного домена установите переменную репозитория `SITE_URL` в полный HTTPS-адрес с завершающим `/`, настройте домен в Pages и повторите публикацию. Она обновит canonical, Open Graph, JSON-LD и sitemap. Нельзя менять URL только в метатегах без настройки самого хостинга.

## Редактирование

- Текст и контакты: `src/index.html`; контакт и адрес в структурированных данных: `scripts/build.mjs`.
- Оформление: `src/assets/styles.css`.
- Приглашение: `src/video.html`. Сейчас это ссылка на предоставленную историю https://vk.ru/story-48919992_456239127. История при проверке 13 октября 2026 года переводит на экран входа VK. Прямой плеер не заявлен работающим.
- Для постоянного видео замените содержимое `src/video.html` официальным iframe из «Поделиться → Экспортировать/Встроить» публичной видеозаписи VK с доступом для внешних сайтов. Для MP4 используйте `<video controls playsinline preload="metadata">` с надёжным HTTPS-источником или локальным файлом. Не подменяйте ID истории ID видеозаписи.
- После любого изменения: сборка, проверка, просмотр страницы, push в `main`.

## Поисковая оптимизация

Реализованы описательный title и description, один H1, естественные тексты о собраниях созависимых и созависимости в Омске, canonical, Open Graph с локальным PNG, JSON-LD Organization/WebPage/FAQPage, sitemap.xml, открытая индексация, доступная навигация и мобильная вёрстка. FAQ в JSON-LD формируется из видимого текста, чтобы ответы совпадали.

После запуска организатору следует добавить сайт в Яндекс Вебмастер и Google Search Console и отправить sitemap. Для GitHub Pages в подкаталоге файл `/soza/robots.txt` не заменяет корневой robots.txt всего домена; ограничения корневого домена контролирует хостинг. При переносе на собственный домен используйте файл из `dist/` в корне сайта.

Реализованные SEO-настройки не означают, что сайт уже проиндексирован или занимает позиции. Адрес и расписание нужно поддерживать актуальными; даты собраний не добавлять в Event-разметку до подтверждения.
