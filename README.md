# Собрание родителей зависимых в Омске

Статический лендинг бесплатного собрания родителей о реабилитации в Омске. Содержание основано на видеоприглашении Евгения Билинзона: родители детей на реабилитации или на пути в центр, программы и качество реабилитации, внутренние услуги центра. Дополнительный раздел помогает родственникам с запросами о поддержке и созависимости уточнить, подходит ли им встреча.

Светлое оформление, адаптивная вёрстка, видео в первом экране, телефон в шапке и закреплённая кнопка звонка, адрес и карта. Содержимое и FAQ работают без JavaScript. Нет внешних шрифтов, аналитики, форм и зависимостей npm.

Контакт: **+7 983 621-21-48**. Место: **Омск, ул. Нефтезаводская, 10, студия подкастов**. Бесплатность собрания подтверждена видео; она не относится к лечению и реабилитации. Календарная дата, время, запись, участие других близких и регулярность встреч уточняются по телефону. Принадлежность к CoDA/Ал-Анон, клинические услуги, лицензии и гарантии результатов не заявлены. Относительное «через неделю» из видео не превращается в вычисленное расписание.

## Локальный запуск

Требуется Node.js 22 или новее. Установка пакетов не нужна.

```powershell
npm run build
npm run check
npm run preview
```

Предпросмотр: http://127.0.0.1:4173. Каталог `dist/` содержит файлы для любого статического HTTPS-хостинга.

## Публикация

Workflow `.github/workflows/pages.yml` собирает и проверяет сайт при push и pull request. При переменной репозитория `PAGES_ENABLED=true` он публикует `dist/` в GitHub Pages при push в `main`. Источник Pages: **GitHub Actions**. Репозиторий открыт по разрешению владельца для размещения на текущем тарифе GitHub.

Основной production URL: `https://soza55.ru/`, хостинг REG.RU, каталог сайта в ispmanager `/www/soza55.ru`. Содержимое `dist/` загружается в корень этого каталога. Исходники остаются в GitHub; GitHub Pages служит дополнительной копией с canonical на основном домене. Домен soza55.ru не привязывается к GitHub Pages через CNAME.

Для Apache сборка включает `.htaccess`: главная `index.html` и собственная страница ошибки 404. HTTPS и перенаправление HTTP→HTTPS настраиваются для soza55.ru в панели хостинга после проверки сертификата. Архив релиза и резервные копии храните вне публичного каталога.

Для другого домена задайте `SITE_URL` как полный HTTPS-адрес с завершающим `/` и повторите сборку. Он обновит canonical, Open Graph, JSON-LD и sitemap; для GitHub Actions доступна одноимённая переменная репозитория. Изменение метаданных не заменяет настройки домена и сертификата на хостинге.

## Редактирование

- Текст, контакты и FAQ: `src/index.html`; адрес, темы и данные видео: `scripts/build.mjs`. Title/description в JSON-LD берутся из HTML.
- Оформление: `src/assets/styles.css`.
- Приглашение: `src/video.html`. Видео из предоставленной истории https://vk.ru/story-48919992_456239127 сохранено с разрешения пользователя 13 октября 2026 года в `src/assets/invitation.mp4`; обложка — `src/assets/invitation-poster.jpg`. Плеер воспроизводит локальный MP4 без входа в VK, не зависит от срока жизни истории и использует `preload="metadata"` для предварительной загрузки метаданных без автоматического воспроизведения. Ссылка на оригинал оставлена под видео.
- Видео содержит полный ролик длительностью около 45,1 секунды без монтажных сокращений: H.264, 720×1280, 30 fps, yuv420p; звук AAC, 96 кбит/с. MP4 подготовлен с `faststart`. Исходный файл сохранён отдельно; учётные данные и временные URL VK не входят в репозиторий. Для замены обновите MP4 и обложку, затем проверьте воспроизведение и звук.
- После любого изменения: сборка, проверка, просмотр страницы, push в `main`.

## Поисковая оптимизация

Основная тема — бесплатное собрание родителей зависимых в Омске. Содержательные разделы раскрывают выбор и качество реабилитационного центра, вопросы его программ и услуг, подготовку к разговору, поддержку семьи и созависимость. Карта из 12 групп поисковых намерений и границы утверждений — в `docs/seo-map.md`; частотность и позиции не выдуманы.

Реализованы title/description, один H1, естественные H2 и тексты, canonical, Open Graph с актуальным PNG, JSON-LD WebPage/FAQPage/Place/VideoObject, sitemap.xml с данными видео, открытая индексация, доступная навигация и мобильная вёрстка. FAQ формируется из видимого текста и проверяется на совпадение; Event не добавляется без точной даты. Дата uploadDate относится к публикации копии ролика на сайте.

После запуска организатору следует добавить сайт в Яндекс Вебмастер и Google Search Console и отправить sitemap. Для GitHub Pages в подкаталоге файл `/soza/robots.txt` не заменяет корневой robots.txt всего домена; ограничения корневого домена контролирует хостинг. При переносе на собственный домен используйте файл из `dist/` в корне сайта.

Реализованные SEO-настройки не означают, что сайт уже проиндексирован или занимает позиции. Адрес и расписание нужно поддерживать актуальными; даты собраний не добавлять в Event-разметку до подтверждения.
